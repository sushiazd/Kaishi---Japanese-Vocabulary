# Kaishi 1.5k (FR)

Learn 1500 words in Japanese: le deck **Kaishi 1.5k** (les 1 500 mots japonais les plus fréquents, avec une phrase d'exemple) traduit en français, dans une app web qui reprend la répétition espacée d'Anki (À revoir / Difficile / Correct / Facile).

## Installer sur l'iPhone

1. Ouvrir le site GitHub Pages du dépôt dans **Safari**.
2. Partager, puis « Sur l'écran d'accueil », puis Ajouter.

L'app fonctionne ensuite hors connexion. La progression est enregistrée sur l'appareil : penser à faire une sauvegarde de temps en temps (Réglages, « Sauvegarder ma progression »).

## Mettre à jour

Après avoir modifié des fichiers, changer `VERSION` dans `sw.js` (par exemple `kaishi-v2`) pour que l'iPhone récupère la nouvelle version.

## Crédits

Données du deck : [Kaishi 1.5k](https://github.com/donkuri/Kaishi) (mots, phrases, furigana, accent de hauteur), traductions françaises faites pour cette app. Audio : synthèse vocale japonaise de l'appareil.
